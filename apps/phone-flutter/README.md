# AJ Audio — Flutter (Android + iOS), D-007

One codebase. Not published to stores: Android = APK sideload, iOS = unsigned `.ipa` → Sideloadly / AltStore with your Apple ID.

v0.2 (this skeleton): sign in, rooms with now-playing + **who is playing** (AJ server), group / ungroup ticked, volume, mute, transport.
"Play my phone" (capture) is native code in android/app/src/main/java (CaptureService).

## Build
Platform folders (`android/`, `ios/`) are generated by CI with `flutter create` (see `.github/workflows/phone-flutter.yml`), so no Flutter is needed on the PC.
Push to GitHub → Actions → **phone-flutter** → download artifacts `aj-audio-apk` / `aj-audio-ipa-unsigned`.

Local (if Flutter is installed): `flutter create --org com.ajnetwork --platforms android,ios . && flutter run`.
Then add to `android/app/src/main/AndroidManifest.xml`: INTERNET permission + `android:usesCleartextTraffic="true"` (CI does this).

## iOS install from Windows
Sideloadly → drag `AJ_Audio.ipa` → Apple ID → Start. Free Apple ID: re-sign every 7 days.
